# 1.1.1 初始开发测试版（versionCode 74，历史说明）

以下记录仅对应 build 74；当前开发行为见[需求](../REQUIREMENTS.md)，后续构建结果保存在 `docs/verification/`。

本版在对话右上角三点按钮外显示上下文使用估算圆环。点击可查看服务器最近一次报告的 token 与模型上下文窗口，并在空闲且已接续的会话中确认手动压缩。账户剩余额度继续单独显示；服务器未报告窗口时圆环仅显示底环。

对话列表支持长按重命名和置顶。重命名由远端保存；置顶为按连接保存的本机显示偏好。搜索改用服务器标题搜索，能查到尚未翻页加载的会话；服务器标题匹配区分大小写。顶部对话名称打开项目／会话详情、Skills 和 MCP 服务信息。Skills 和 MCP 使用分组名称列表，可搜索名称并点开单项详情。详情补充模型、推理强度、权限、速度和远端版本。输入框下方模型显示名仅缩短开头的 `GPT-`。

右上角圆环和三点图标在上一构建基础上同步放大 13%。只读历史确认压缩后会先接续，仍为同一空闲对话时才发送压缩请求。MCP 状态组只显示有成员的分类；点击服务器名称后按名称加载完整关键详情，包括服务信息、工具、资源、资源模板及能力。新增界面文字覆盖现有十种语言。自动化使用合成协议与回环 SSH 夹具；目标手机显示、实际远端 Codex 版本对新接口的支持和 Tailnet 安装仍需设备验收。最新构建的完整结果见[圆环、MCP 与压缩修正验证记录](../verification/2026-10-30-1.1.1-mcp-compaction.md)；上一构建见[目录修正验证记录](../verification/2026-10-30-1.1.1-directory-refinement.md)。
