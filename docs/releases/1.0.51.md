# RemoteGPT 1.0.51

通过 SSH 在 Android 手机上操作远端 Codex，以原生界面处理对话、执行进度、审批和附件，无需另行手动部署 Web 服务。

**小而美，轻量便捷。** APK 约 3.8 MB（不到 4 MB），不内嵌模型；原生界面配合统一图标、深色主题和状态卡片，减少手机操作中的来回切换。SSH 直连自己的服务器，无额外 Web 中转，配合断线恢复机制继续工作；实际速度和稳定性取决于网络与服务器。约 4 MB 指安装包体积，安装后的空间会随系统展开和缓存变化。

## 特色功能

- **流体云／实时通知与会话气泡**：显示思考、执行、待审批和完成状态。权限请求可从通知允许或拒绝，补充信息可直接返回对应会话填写。是否展示为流体云取决于系统、厂商与通知授权。
- **交互式审批**：命令执行和文件修改请求使用原生弹窗；方案选择与补充信息使用可点击表单。权限选择随下一轮消息生效。
- **临时强制允许**：同一对话前 30 秒已有 3 次不同的实时权限请求时，第 4 次及后续符合条件的弹窗提供红字“全部允许(强制)”。确认后仅自动允许权限请求，方案选择和补充信息仍手动回答；新权限成功生效或断开后结束，也可手动关闭。
- **断线后远端继续运行**：默认启用 Python 持久托管，SSH 断线后模型进程可继续工作，重连补回输出与待处理请求。
- **自动重连与活动会话恢复**：短暂断线后尝试重连，恢复可恢复的活动会话。仅浏览旧历史不会自动接续或发送消息，历史对话可手动接续。
- **多会话并行**：同一连接运行多个会话，各自保存草稿、附件、权限和通知；切换会话不停止其他任务。
- **图片与文件**：支持上传、图片缩放预览、消息复制和附件保存。每条最多 4 张图片（每张 20 MiB）及 8 个文件（每个 100 MiB）。
- **连接诊断与远端设置**：首次连接检查 Python、Codex、SFTP 与登录状态；按服务器能力选择模型、推理强度和速度，查看公开的账户额度。

## 下载与配置

在本页 Assets 中下载 `RemoteGPT-1.0.51-Android-universal-debug.apk`，或者附 LICENSE 的安装 ZIP。GitHub 自动提供的 Source code 是源码，不能直接安装。

1. 手机需要 Android 8 或以上，并能访问服务器 SSH 地址。
2. 服务器需要 SSH/SFTP、同一 SSH 用户已配置可用的 Codex CLI；默认持久模式需要完整 Python 3.8 或以上。
3. 应用中填写 SSH 地址、用户、认证方式与项目目录；启动命令默认为 `codex app-server`，必要时填写 Codex 绝对路径。
4. 核对首次连接的主机指纹，创建或接续对话，手动发送消息。
