# RemoteGPT 1.0.66

- Interface support for English, 简体中文, 繁體中文, 日本語, 한국어, Español, Português (Brasil), Deutsch, Français and Русский.
- Follows the phone’s language by default; choose another in Settings → Language.
- Reasoning effort names stay in English. Server messages and errors retain their original text.
- Fixes stale-language model sync messages and cached conversation names in notifications.

Android 8+. Download and install the APK.

---

- 界面支持英文、简体中文、繁体中文、日文、韩文、西班牙语、巴西葡萄牙语、德语、法语和俄语。
- 默认跟随系统，可在“设置 → 语言”中切换。
- 推理强度档位保持英文名称；服务器消息和报错保留原文。
- 修复模型同步提示和通知缓存会话名称中的旧语言残留。

支持 Android 8+，下载 APK 安装。
