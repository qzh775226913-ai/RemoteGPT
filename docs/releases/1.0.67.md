# RemoteGPT 1.0.67

- Localizes client-generated connection and operation diagnostics in all ten interface languages. Original server errors, exception messages and diagnostic output retain their original text.
- Preserves remote speed option names, descriptions and order, including an explicitly supplied default tier. Older catalogs retain the implicit Standard option where needed.
- Keeps models in the order returned by the remote server across catalog pages, without sorting by name or default markers.
- Includes the ten-language interface introduced in 1.0.66. Follows the phone’s language by default; change it in Settings → Language. Reasoning effort names remain in English.

Android 8+. Download and install the APK. Keeps the existing package ID, signing certificate and data formats.

---

- 客户端生成的连接与操作诊断支持十种界面语言；服务器错误、异常消息和诊断输出保留原文。
- 速度选项保留远端名称、说明和顺序，包括显式提供的默认档；旧目录缺少普通档时保留隐含的 Standard 选项。
- 模型跨分页保持远端返回顺序，不按名称或默认标记重排。
- 包含 1.0.66 的十语言界面，默认跟随系统，可在“设置 → 语言”中切换；推理强度档位名称保持英文。

支持 Android 8+，下载 APK 安装。沿用现有包名、签名证书与数据格式。
