# 1.1.1 开发测试版

本版在对话右上角三点按钮外显示上下文使用估算圆环。点击可查看服务器最近一次报告的 token 与模型上下文窗口，并在空闲且已接续的会话中确认手动压缩。账户剩余额度继续单独显示；服务器未报告窗口时圆环仅显示底环。

对话列表支持长按重命名和置顶。重命名由远端保存；置顶为按连接保存的本机显示偏好。搜索改用服务器标题搜索，能查到尚未翻页加载的会话；服务器标题匹配区分大小写。顶部对话名称打开项目／会话详情、Skills 和 MCP 服务信息。Skills 和 MCP 使用分组名称列表，可搜索名称并点开单项详情。详情补充模型、推理强度、权限、速度和远端版本。输入框下方模型显示名仅缩短开头的 `GPT-`。

新增界面文字覆盖现有十种语言。自动化使用合成协议与回环 SSH 夹具；目标手机显示、实际远端 Codex 版本对新接口的支持和 Tailnet 安装仍需设备验收。完整验证结果见[1.1.1 验证记录](../verification/2026-10-30-1.1.1.md)。
