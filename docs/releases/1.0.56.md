# RemoteGPT 1.0.56 开发测试版

Android versionCode：58。最低 Android 8，包名和签名身份保持不变。GitHub 稳定发布仍为 1.0.55。

- 对远端正文中明确标记的行内与独立 TeX 公式进行本地原生排版，支持分式、上下标、上横线、根式、希腊字母、求和／积分和常用矩阵／对齐环境。
- 独立公式及过长的行内公式可横向滚动；独立公式长按复制保留原始标记和 TeX，消息复制保留完整原文。
- 流式补充文字时保留已有公式和横向阅读位置；窗口移除后不发布迟到的排版结果。
- 修复反三角函数及简写分式未排版、Ω 丢失和带边框公式字母空心的问题。
- 修复长回复在第 64 个公式之后退回原始文本的问题，单个正文块处理上限调整为 512 个。
- 提高浅色界面次要文字及连接状态的对比度。
- 代码、普通货币、不完整或不支持的公式保留原文。排版不执行宏定义、外部资源或远端代码。

排版需要远端实际返回公式标记；没有更改模型、账户或服务器配置。已保留 [第三方组件许可与源码入口](../THIRD_PARTY.md)。合成文本绘制与协议测试不代替真机及真实模型验收。
