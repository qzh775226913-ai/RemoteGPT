# 使用说明

适用版本：1.0.51。手机通过 SSH 操作远端 Codex，账户与模型服务在服务器上配置。

正常使用（包括工作和商业项目）免费；本人或组织内部修改可以进行。换皮／修改版发布、闭源产品交付和利用 App 提供商业产品或服务，须另获书面授权。完整条件见 [项目许可](../LICENSE)。

## 1. 准备服务器

先用其他 SSH 客户端确认能登录目标主机。应用还需要该用户可使用 SFTP、家目录可写，并能访问项目目录。

用**同一个 SSH 用户**按 [Codex 官方说明](https://learn.chatgpt.com/docs/codex/cli)安装、配置登录和模型服务。使用 Codex 登录时执行 `codex login`；无浏览器环境可使用 `codex login --device-auth`。已有 API 或其他受支持的配置时，沿用该用户的有效配置即可。

检查程序与协议入口：

```sh
command -v codex
codex --version
codex app-server --help
```

默认持久模式还要求 `python3` ≥ 3.8，且标准库支持 SQLite、文件锁和 Unix socket：

```sh
python3 -c 'import sys, sqlite3, fcntl, socket; assert sys.version_info >= (3, 8); assert hasattr(socket, "AF_UNIX"); print("Python OK")'
```

这些是环境检查，不会验证模型请求能否成功。确认远端 Codex 能正常使用后再配置手机。交互终端与非交互 SSH 的 PATH 可能不同；应用的连接诊断按后者检查。

应用会自动启动 App Server；无需手动常驻运行。持久模式会自动在 `~/.remote-gpt` 写入托管脚本和会话数据。Linux 或 macOS 远端须满足上述 Unix 环境要求；当前自动化未覆盖真实 macOS 主机。

## 2. 配置手机

安装来源可信的 APK，要求 Android 8 或以上。自行构建方法见 [开发手册](DEVELOPMENT.md)。在应用的远程控制菜单选择“添加连接”：

| 字段 | 填写方式 |
| --- | --- |
| 主机、端口 | 手机可达的服务器地址和 SSH 端口；默认端口 22 |
| 用户名 | 上一步安装／配置 Codex 的系统用户 |
| 认证方式 | 密码或私钥；加密私钥同时填写口令。Tailscale SSH 身份认证需另有相应策略授权 |
| 远端项目目录 | 服务器上的绝对路径，可留空后通过目录浏览选择 |
| 远端启动命令 | 默认 `codex app-server`；找不到程序时填写 `command -v codex` 得到的完整路径加 `app-server` |
| 远端持久会话 | 建议保持开启，需要上述 Python 环境 |

例如程序路径为 `/home/me/.local/bin/codex`，启动命令填：

```text
/home/me/.local/bin/codex app-server
```

连接时通过可信渠道核对服务器的 SSH 主机指纹，再确认信任。选择项目目录，创建对话或接续历史，然后手动发送消息；仅浏览历史不会自动发送或接续。

使用 Tailscale 地址时，手机需先连接对应 tailnet，且网络策略允许访问。Tailscale 网络连接与 Tailscale SSH 免密码认证是两项配置；普通 SSH 仍需密码或私钥。

## 3. 日常使用与权限

- 多个会话分别保存草稿、附件和权限选择；执行中可以补充输入，或排队下一条消息。
- 每条消息最多 4 张图片（每张 20 MiB）和 8 个普通文件（每个 100 MiB）。图片格式取决于手机解码能力。
- 权限菜单提供沿用远端、按需审批、只读和完全访问；**更改后需发送消息，下一轮才生效**。“只读”仍可能读取文件或使用允许的工具，不代表免费聊天。

同一对话前 30 秒内已有 3 次不同的实时命令／文件权限审批时，第 4 次及后续符合条件的审批弹窗才提供红字“全部允许(强制)”。确认警告后，该对话临时自动允许权限请求，并显示红色闪电；方案选择和补充信息仍正常提问。

启用时下一轮选择设为完全访问，仍可改选其他权限；新权限随下一轮成功生效后，临时授权结束。也可点击权限菜单中的“强制允许”关闭；断开连接会清除临时授权。未启用时，正常权限菜单不显示该项。

## 4. 常见问题

| 问题 | 处理方式 |
| --- | --- |
| SSH 认证失败 | 检查主机、端口、系统用户和认证信息；Tailscale SSH 另检查身份与策略 |
| 主机密钥变化 | 先确认服务器是否更换密钥，不直接忽略警告 |
| 找不到 Codex | 用同一用户检查安装；在启动命令中填写绝对路径，并确认其运行环境在非交互 SSH 中可用 |
| 找不到 Python／版本过低 | 安装完整的 Python 3.8 或以上，使非交互 SSH 能运行 `python3`；只改 Codex 启动路径不能解决 Python 问题 |
| 暂时无法安装 Python | 在连接配置关闭持久会话，或在诊断错误中明确选择关闭后重连；断线续跑不保证，版本维护和部分问答恢复不可用 |
| SFTP 或托管写入失败 | 检查 SSH 服务的 SFTP 支持、家目录权限和磁盘空间 |
| App Server 报告未登录 | 用同一 SSH 用户完成远端 Codex 登录或检查已有账户配置，再重连 |
| 已连接但模型请求失败 | 检查远端模型服务的网络、账户权限、额度与配置；环境诊断通过不保证上游可用 |

持久会话依赖远端托管进程存活。主机重启、进程崩溃、手机强杀后的恢复，以及厂商通知／后台表现不作无条件保证；完整证据范围见 [验收边界](ACCEPTANCE.md)。
