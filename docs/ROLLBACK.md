## 源码恢复

先保存工作区变更，再从对应基线建立恢复分支，或按依赖倒序 revert 已提交阶段：

```sh
git status --short --branch
git switch -c recovery/from-baseline <baseline-commit>
```

```sh
git revert <change-commit>
```

## 数据与分发

- 源码回退不撤销已发布 Release、下载副本或远端已执行任务。
- Android 低 versionCode 覆盖安装受系统限制；卸载会清除本机应用数据。
- 版本回退需保留包名、签名及数据格式，并核对目标设备安装条件。
- 远端托管脚本与运行进程的恢复独立于 Git；更新前记录其版本和活动任务。
- 已公开版本标签保留原指向，常规维护采用新提交。
