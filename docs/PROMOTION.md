# 项目简介

RemoteGPT 是通过 SSH 操作远端 Codex 的 Android 原生客户端。支持多会话、任务状态、权限审批、附件传输、远端持久会话和断线恢复。APK 约 3.8 MB，最低 Android 8。

服务器需提供 SSH/SFTP，并为连接用户配置可用的 Codex CLI。持久模式需要 Python 3.8+。模型运行、账户权限和服务费用由远端处理。
