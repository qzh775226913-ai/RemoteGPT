# 项目简介

RemoteGPT 是通过 SSH 操作远端 Codex 的 Android 图形化客户端。通过目录与会话列表、审批按钮、问题表单、模型选择面板和附件预览，在手机上查看和操作远端任务。支持多会话、远端持久会话和断线恢复。APK 约 3.8 MB，最低 Android 8。

适合已有 Codex CLI 和 SSH 环境的 Android 用户。服务器需提供 SSH/SFTP，并为连接用户配置可用的 Codex CLI。默认持久模式需要 Python 3.8+；恢复依赖远端托管进程存活。模型运行、账户权限和服务费用由远端处理。项目为独立客户端，与 OpenAI 无隶属关系。
