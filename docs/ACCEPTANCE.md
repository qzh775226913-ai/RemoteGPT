# 验收标准与证据边界

适用需求：[R-01 至 R-20](REQUIREMENTS.md)。最后核对：2026-10-12。本文件描述通过标准，当前结果记录在 [1.0.49 验证](verification/2026-10-12-1.0.49.md)；之前的 [1.0.48 验证](verification/2026-10-11-1.0.48.md) 和 [项目整理验证](verification/2026-10-11.md) 保留作追溯。

## 自动化合并门槛

完整验证入口：

```sh
.venv/bin/python tools/verify.py
```

必须满足：文档链接／需求编号／模块登记／源文件规模检查通过；生成图标一致；Python 测试通过；Android 测试 0 失败、0 错误、**0 跳过**；APK 构建成功；Lint 0 Error/Fatal。既有 Warning 必须记录，新增警告需说明。仅 `--unit` 或 `--python-only` 成功不能标记完整验收；过去的报告不能代替本轮执行。

测试使用合成 RPC、Robolectric 原生绘制及只绑定 127.0.0.1:22228 的 SSH/SFTP 夹具。它证明应用逻辑、协议往返、实际本地 SSH 传输、布局和恢复规则；夹具的假 App Server 不是 OpenAI 模型后端。

## 每次涉及状态修改必查

1. A 工作时切到 B，A 的输出、审批和完成只更新 A；通知打开正确会话。
2. 停止／失败／断线／历史重放不误发排队消息；新连接不接收旧连接的回调。
3. 浏览历史不取得写入者；接续准备中的文字／图片／文件保持，接续本身不发送。
4. 审批和问答响应一次且身份正确；失败保留待处理请求，重连后旧通知 token 失效。
5. 嵌套背景分发或异常后恢复当前选中会话，再通知 UI；只能在主线程读写会话容器。
6. Activity 旋转／销毁释放窗口和监听器，不重启 SSH，不把选择结果或附件放到其他对话。
7. 附完整选项列表的异步提问副本只显示一张交互卡片；保留额外说明、图片、缺失选项、不同身份或轮次的真实回复，不修改服务器消息／模型上下文。
8. 同源缩略图在重连和阅读冻结时恢复；两次临时失败后第三次可成功，永久失败不超过 3 次，点按能重新尝试；离屏／销毁取消计划重试，旧连接结果不发布。
9. 问答回答完成、同轮次继续输出或接续恢复后，原卡片保持在原调用／工具旁；多题按源消息排序，同题的后续调用不取得此前答案。无来源的进程内卡片保留第一次已观察位置；完成快照与缺轮次的迟到事件保留原消息轮次。

具体回归入口已映射在需求表；涉及一项行为时执行相关定向测试，交付前仍执行完整入口。

## 自动化无法代替的验收

| 范围 | 还需什么证据 | 可报告的边界 |
| --- | --- | --- |
| Android/厂商通知 | 目标手机的通知权限、锁屏操作、气泡弹出、实时通知资格及多卡片展示 | 自动化只验证应用提交的通知和路由；不能报告 ColorOS/OriginOS 已验收 |
| 后台与网络 | 目标设备切 Wi-Fi/Tailscale、Doze、系统强杀、再次进入恢复 | 托管存活和本地重放测试不等于所有手机后台联网成功 |
| 真实 Codex | 指定 CLI 版本、登录方式、模型、服务器能力下的实际事件和响应 | Schema/夹具兼容不等于真实模型一定返回思考摘要、结构化问题或新速度档位 |
| Tailscale SSH | 实际 tailnet 身份和 SSH 策略、手机路由 | 模拟免密码身份测试不等于真实 tailnet 已授权 |
| 图像格式 | 目标设备真实 HEIF/AVIF、云相册 URI、长图与缩放 | 平台可解码才支持；Robolectric 的分区解码 shadow 不是目标硬件解码器 |
| 更新和分发 | 实际目标安装方式、安装包签名、覆盖安装、下载与校验 | 构建成功不代表已发布、已安装或真实远端升级完成 |

本轮没有目标 Android 真机或真实模型验收；保持这项限制，不能把代码重构写成新增支持。
