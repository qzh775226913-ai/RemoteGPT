# 验收标准与证据边界

适用：1.1.1 / versionCode 89（开发测试版）；需求 R-01 至 R-32。最后核对：2026-11-03。

产品行为、数值限额和测试入口统一见 [需求与测试映射](REQUIREMENTS.md)。本文件按风险组织验收；历史修复、截图和构建结果保存在 `docs/verification/`，不得将旧报告或调查建议当作当前已验收能力。

## 自动化合并门槛

完整验证入口：

```sh
.venv/bin/python tools/verify.py
```

必须全部满足：

- 文档本地链接、需求编号／测试映射、模块登记和源文件规模检查通过。
- 图标与数学字形生成检查、Python 测试通过。
- Android 测试至少一项，失败、错误、**跳过均为 0**。
- APK 构建成功，Lint 0 Error/Fatal；记录 Warning 数量及变化，不通过降级或屏蔽掩盖问题。

仅 `--unit`／`--python-only` 成功是局部验证。测试使用合成 RPC、Robolectric 原生绘制及仅绑定 127.0.0.1:22228 的 SSH/SFTP 夹具；假 App Server 不调用 OpenAI 模型，不读取真实 Codex 凭据，也不重启生产任务。环境和报告路径见 [开发手册](DEVELOPMENT.md)。

## 会话、协议与失败恢复

| 需求 | 必查场景 |
| --- | --- |
| R-01～R-03 连接与协议 | 验证表单、认证取消、指纹变化、分片／并发／服务器请求、未知交互拒绝。缺 Python、Codex、SFTP 和托管写入失败分别提示；持久模式不得静默降级，自定义启动器不额外启动；诊断无凭据，公开登录检查不调用模型，迟到初始化不能发布已连接 |
| R-04～R-05 持久与隔离 | A 工作时切到 B，输出、停止、审批、完成、草稿和通知只归所属会话。断线后恢复基线、有序输出和待审批，不重发旧 turn/start。嵌套分发和异常后先恢复选中会话／项目再通知 UI；worker 不得访问会话容器或更新 View |
| R-06～R-08 历史与队列 | 浏览历史不占写入者、不更新远端时间；读取时接续按钮禁用但不显示接续中，后台恢复不改变当前按钮，写入者冲突回退只读。接续保留草稿和附件但不发送；仅实时成功完成触发待发消息，失败／停止／断线／重放／只读不误发，取消返还附件 |
| R-09、R-12 权限审批 | 验证 30 秒含边界、第 4 次唯一实时权限请求才提供强制允许，重复／重放／表单／跨会话不计数；资格在到达时固定。取消不授权，普通菜单不能开启；确认后仅本会话权限请求自动回答一次，表单和未知请求不自动回答。失败保留手动入口并结束授权；重放屏障、断开、迟到响应和权限 revision 不串授权。下一轮成功只结束它实际应用的授权，失败或旧轮完成不结束。普通权限面板、红字按钮／闪电和窗口释放均核对；自动审查与人工模式的 reviewer 字段、沙盒格式正确，原图标保持 |
| R-10 结构化问题 | 原生／异步问答与完整选项副本正确合并，额外说明、图片、不同身份／轮次不隐藏；卡片保持在原调用位置，同轮次后续同题不得拿到较早答案。问题／选项可选择复制，缩小／恢复不发送或取消；旋转、A/B 切换、重放和异常后恢复非秘密草稿，秘密输入不存档，失败可重试 |
| R-11、R-30 模型目录 | 不开面板也定时同步，慢请求不重叠、失败保留旧目录，断开取消、重连只有一个定时器；完整分页与远端顺序、名称／描述／ID 保留，未来档位不猜能力，default 与 fast/priority 精确区分。首次与后续状态同一显示入口；推理档位保持英文。模型名仅按 R-30 改显示分隔符，目录和请求 ID 不变 |
| R-13～R-14 附件与文件 | 系统来源／回退、多选、取消、超限、部分成功、原字节和文件名边界；切换／迟到结果不串连接或会话。真实 SSH channel-open 首次拒绝时只重试建立通道一次，不重放传输，持续失败有界提示且 RPC 可用。保存窗口 MIME／扩展名匹配，未知类型保留二进制，失败清理部分目标 |
| R-16、R-19 错误与维护 | 空摘要／元数据不覆盖标题；历史错误与连接错误分开，不推测未公开推理。区分运行版本与安装版本，检查失败不称最新，更新／重启由明确操作触发，不自动停止活跃任务 |
| R-18、R-27 额度与上下文 | 账户额度与会话 token 分开；A/B token 事件不串，未知／断线不显示假比例。上下文入口点击区、明暗主题与无障碍正确；压缩确认、忙碌阻止、只读接续后等待重放再发、切换取消、失败及压缩状态文案正确 |
| R-28～R-29 列表与能力目录 | 项目原地折叠、新建按钮独立操作、图标和分页保留；长按重命名失败保留旧标题，成功更新列表和当前会话，置顶按连接隔离。标题搜索覆盖未加载页，快速切换丢弃旧响应。Skills／MCP 按状态分组，无成员组隐藏，搜索／空／断开／错误明确；MCP 单项按 serverName 请求 full，分页有界，关闭后迟到结果不发布，远端内容保留 |

## 绘制、触摸与窗口生命周期

以下均按需求中的尺寸、预算和上限检查；合成截图不能替代目标手机的触摸、字体和动画验收。

| 需求 | 必查场景 |
| --- | --- |
| R-15 图片 | 命令徽章、思考、代码／转义示例不进缩略图或画廊；显式结构化图片和正文真实链接保留，折叠工具组按事件顺序展示图片，流式与历史一致。重连及阅读冻结恢复缩略图，最多三次尝试、点按重试、离屏取消。路径与内嵌数据同源回退；私有原图副本按服务器／会话／消息／路径隔离，仅文件确实不存在且无部分输出时回退，权限／网络失败不回退，重复路径不猜来源。画廊冻结顺序、规范化去重、首尾不循环，保存当前页；放大拖动与边缘翻页分开。当前图成功后仅预取相邻两张，在途复用、取消过时任务，后台失败静默；三张缓存和内存／文件预算淘汰正确，阻塞旧读取不独占新页。关闭／换作用域释放原图和临时文件，不回收共享缩略图 |
| R-15 复制反馈 | 复制图标单层圆形反馈、32dp 遮罩、48dp 点击区；用户消息右下对齐，边缘点击一次。Android 8／35、密度、尺寸和明暗主题检查像素及边界 |
| R-20、R-23～R-26 窗口与语言 | 十语言键、参数、数量、日期及比例一致，远端文字／复制原文不翻译；切语言不触发授权，通知、快捷入口与页面刷新。320dp、240dp 历史按钮及大字号无裁切。五档字号兼容旧值且不重写；连接窗口可截图、输入遮挡和 12dp 按钮间距保留。说明区有界滚动、操作可见；折叠摘要按字形光学居中，矢量符号对齐。旋转／销毁释放监听器、不重启 SSH，系统选择器结果不串会话 |
| R-21 公式 | 四种显式标记、反正切、简写分式、Ω、边框前后实心字形、中英混排；主题／字号、行内基线、长式横滑和原文复制。代码／货币／转义保护，流式闭合／替换、历史及 detach/reattach 迟到结果正确。超限、深层、不支持、宏或外部资源回退原文；重复绘制不受 Paint 污染。浅色正文／次要文字和连接状态对比度至少 4.5:1 |
| R-22 表格 | 同列宽／行高、表头同字号加粗、紧凑留白与较小公式；边线及交点均为同色同粗 1 物理像素，无双线或叠加变深。外层分发的横滑含轻微纵向偏移、松手焦点不改纵向位置，纵滑仍浏览消息，取消／detach 释放保护。Android 8／35、宽窄表、追加行对象／位置保持、重复表头独立、公式链接／复制、CRLF／转义竖线、无效／超限／代码回退均检查 |
| R-31 执行详情 | 同回合按正文边界分组、思考不加数量前缀，简繁中文数量无多余间隔，超宽摘要可横滑且不误点。原文顺序、代码／diff 着色、逐文件与最终统计一致，头行不计增删、文件名数字不误判、汇总不重复；patchUpdated 的先到／重复／错误轮次／完成后迟到及重放均核对。变化数字有界合并并停靠，任务结束静止，结束不重建代码；最终前三项与更多可反复展开。全屏代码详情锚点缩放、双轴拖动／惯性／边缘、选择复制及实时更新保持缩放，离屏不继续重绘 |
| R-24、R-32 输入区与滚动 | Android 8／35、明暗主题、320dp／宽屏、十语言和大字号；键盘 Insets、空／三行／输入中四行／手动八行草稿、附件与历史切换正常。无消息主页保持输入区展开，有消息后按方向迟滞；按住手指时顶部动画不拉动消息，反向和子视图触摸不漏收缩，原生惯性／回弹仍可用。内部布局补偿不误判到底，滑到底跟随稳定，一次跳转停止旧惯性，新手势可读历史；普通文字／空白点按展开且不弹键盘，链接／按钮／长按／滑动不误触发。模拟 8ms 帧、反向、动画中输入高度／附件变化；中间帧最后消息不遮挡、尺寸不超调或末帧突变，留白不逐帧重排，跳转按钮随输入区。放大按钮不参与文字测量，气泡圆角／内凹表面／发送点击区、八行顶部排版、接续状态稳定尺寸及与跳转按钮避让均检查；无变化附件／待发控件不重建 |
| R-17 通知 | 每会话独立通知／气泡，普通状态无审批按钮，待答入口／完成确认正确，动作绑定连接／会话／请求，旧 token 失效且锁屏操作遵守解锁要求；语言切换不重置频道用户设置 |

## 自动化无法代替的验收

| 范围 | 仍需的实际证据 |
| --- | --- |
| Android／厂商通知 | 目标手机的通知权限、锁屏、气泡、实时通知资格和多卡片；不能由 mocks 声称 ColorOS／OriginOS 已通过 |
| 后台与网络 | 手机切 Wi-Fi／Tailscale、Doze、系统强杀和重新进入恢复；本地托管存活不证明所有后台网络可用 |
| 真实 Codex | 指定 CLI、登录方式、模型和服务器能力下的事件／响应；Schema 和夹具不证明真实摘要、问题或新档位可用 |
| Tailscale SSH | 实际 tailnet 身份、策略和手机路由；模拟免密不证明已授权 |
| 设备绘制与媒体 | 实际输入法动画、触摸／惯性、字体、HEIF／AVIF、云相册 URI、长图；Robolectric 解码 shadow 不代表硬件解码器 |
| 更新与分发 | 目标包签名、覆盖安装、下载路径与真实远端更新；构建成功不证明已发布或安装 |
