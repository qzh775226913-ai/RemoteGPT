# 1.1.0 原生公式排版验证

日期：2026-10-22。版本：1.1.0 / versionCode 57。开发前恢复基线：`a88fda8`。稳定发布仍为 v1.0.55；本版在独立开发分支交付测试。

## 范围

- MathMarkup 识别四种显式公式标记，保护代码、转义、链接地址、普通货币及未闭合片段。
- MathRenderer 使用固定的未修改 JLaTeXMath Android 0.2.0，在单 worker 内进行有界排版与缓存；命令／环境采用允许列表，不加载远端资源或执行宏定义。
- MathSpan 支持正文基线及行高；MathContentView 拥有异步 generation、detach／reattach、长式滚动及复制。已有公式和横向阅读位置在流式追加时保留。
- MessageBodyView 仅将含显式公式的正文交给新组件。ChatItem、ConversationState、传输、存储及模型配置均保持原行为。

## 边界

[App Server 官方事件说明](https://learn.chatgpt.com/docs/app-server)定义代理消息文本增量。本轮合成事件／历史测试验证 TeX 字符、反斜杠和换行原样通过；没有调用真实模型，不能保证每种模型都会返回公式标记。

未进行目标手机安装、动态交互或真实模型验收，不承诺与官方应用跨设备逐像素一致。支持范围与原文回退限制见需求 R-21；自定义宏、外部资源及完整 TeX 文档不受支持。
