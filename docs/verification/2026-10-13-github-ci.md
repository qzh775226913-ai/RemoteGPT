# 首次 GitHub CI 配置修复

日期：2026-10-13。应用仍为 1.0.51 / versionCode 52。

## 原因与变更

基线提交：`709a06b`。首次 [Actions 运行](https://github.com/qzh775226913-ai/RemoteGPT/actions/runs/38349503145) 在 `android-actions/setup-android@v3` 阶段失败，尚未开始项目测试。日志确认该 Action 默认执行 `sdkmanager tools`，失败为 `Failed to find package 'tools'`。

工作流显式设置 `packages: platform-tools`，随后沿用原有步骤安装 `platforms;android-36` 与 `build-tools;35.0.0`。[Action 参数定义](https://github.com/android-actions/setup-android/blob/v3/action.yml) 支持覆盖 `packages`。应用代码、JDK、SDK 目标、Gradle、依赖与 Action 版本均未升级；仅修复 CI 初始化。
