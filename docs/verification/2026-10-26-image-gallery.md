# 2026-10-26 对话图片连续浏览

需求 R-15；恢复基线 `8a8f6e0`。用户要求在对话图片的大图预览中左右翻看其他图片；与本轮浅细表格边框调整一并交付。

## 实现与状态归属

MediaFiles 在主线程收集当前对话已加载消息的图片，按消息与附件顺序规范化路径、去重；ImageDialog 复制该列表为本次窗口快照。页号、加载 generation、原图与失败状态只属于窗口，不写入会话容器，不增加持久化字段。MainActivity 仅连接消息入口与草稿单图入口，并检查原连接／服务器／会话身份；切换会话关闭原窗口。后台 I/O 不读取临时会话选择，主线程发布与保存时核对原会话。

适配显示时横滑翻页；放大时优先拖动，只有从已到达的水平边缘开始向外横滑才翻页，首次拖到边缘不会同次误翻。双指与双击不翻页，翻页重置缩放，首尾不循环，显示当前序号。保存使用当前图片来源。

每次翻页取消旧读取、移除旧排队任务并检查 generation；迟到结果／错误不能替换新页。原图与临时文件在翻页、关闭后释放，共享缩略图不回收。失败可重试当前页，原有草稿预览行为保持。

## 验证

新增 ImageGalleryTest：实际滑动、首尾边界、当前图片保存、列表快照、原图释放／缩略图借用、快速连续翻页与旧任务清理、失败重试、失效连接保护、跨消息图片收集与换会话关闭。扩展 ZoomImageViewTest 检查放大后左右边缘翻页与内部拖动不翻页。定向与最终完整结果待完成后记录。

## 边界

合成 PNG／Robolectric 与回环 SSH/SFTP 不等同于目标手机触摸手感、真实云相册、厂商系统或模型服务验收。没有调用模型或读取真实凭据；目标手机需安装新版后确认。
