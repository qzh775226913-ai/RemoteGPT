# 1.0.57 表格与浅色区域层次

日期：2026-10-24。版本：1.0.57 / versionCode 59。开发前恢复提交：`d2cc20d`。

## 变更与边界

- R-22：正文中的 Markdown 竖线表格按原生行列显示，表头、网格、对齐与有界列宽；超出屏幕时整张表左右滚动，窄表适配可用宽度。
- 流式追加复用原表格与已有单元格，保留横向位置；同表头的不同表格按出现顺序各自保留位置。单元格沿用既有 Markdown／公式显示，复制保留原始表格及消息。
- 围栏代码先拆分，不作为表格解释。无效表头、空格排版、不完整分隔行及超限表格保留完整原文；识别正文竖线表格，不承诺完整 Markdown 容器或 HTML 表格实现。
- 单正文最多 131072 字符、32 张表、1024 个单元格；单表最多 32 列与 128 行（含表头）。列内容自然宽按 80–280dp 估算，窄表可扩展填满可用宽度；超过列宽的内容在单元格内换行。
- 浅色页面底色 #F5F6F7、回复卡片 #FFFFFF、输入框／用户消息／表头 #ECEEF1、计划 #EFF1F4、分界线 #D9DDE2。保留布局及正文／次要文字颜色。
- 原始 ChatItem、ConversationStore、协议及存储格式不变，无新依赖；表格滚动与绘制状态仅由当前 View 持有。
