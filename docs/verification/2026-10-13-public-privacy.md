## 审计结果与限制

初始基线可达历史扫描了 545 个文件版本，未发现私钥块、常见 GitHub Token 或 OpenAI Key 模式。当前可疑密码字段逐项检查均为合成测试值；未跟踪凭据文件。提交邮箱使用 GitHub 隐私邮箱。公开下载 APK 未匹配本次核查的个人目录、主机名及网络地址；发布任务日志未发现上述 Token 模式，四张图片无 EXIF。

这些是模式扫描和人工核查的结果，不能证明任意形式的秘密不存在。两张撤下图片及原始环境信息仍存在于旧提交、`v1.0.51` 标签及旧源码快照中，可能被复制或缓存。本轮仅减少当前页面与源码的暴露，不声明完成历史清除；未经单独授权不重写已公开历史。

GitHub 连接器未提供仓库 About／Topics 修改接口，现有 SSH 部署密钥只能用于 Git 推送；建议字段已写入 [推广资料](../PROMOTION.md)，尚未写入仓库元数据。

应用 Java／Python 代码、配置格式、版本、签名及生产远端任务均未修改。本轮仍需保留真机、厂商通知、真实模型及网络兼容的原有验收边界。
