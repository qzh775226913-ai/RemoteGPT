# 1.0.56 公式修复与浅色可读性验证

日期：2026-10-22。版本：1.0.56 / versionCode 58。修复前恢复提交：`0b067ce`。

## 变更

- 公式功能由早期 1.1.0 开发编号调整到 1.0.56；versionCode 58 高于早期测试包 57，保留包名、签名及存储格式。
- 单个正文块的公式处理上限由 64 调整为 512，覆盖长回复后半段简单变量也失去排版的问题；保留输入长度、公式大小及有界工作队列。
- 补充反三角函数命令。针对反馈中的六个公式验证简写分式、角速度与框选表达式。
- 隔离文字与线框 Paint，避免框线使后续字母变成空心。
- 从固定哈希的原始字体提取 15 个 U+00AD 轮廓，通过字体映射绘制，避免 Android 软连字符处理隐藏 Ω 或其他数学符号；未修改依赖版本及原始字体。
- 浅色次要文字由 #777777 改为 #626262，连接状态由 #309470 改为 #247A5B；保留布局及背景层次，深色配色不变。

## 验证范围

原生绘制回归覆盖 Ω 可见像素、框线前后字形一致、缓存重复绘制、反馈中的六个公式，包含 103 个公式的长回复，以及浅色文字在五种实际背景上的对比度（至少 4.5:1）。生成明暗主题完整会话截图及公式参考截图。

完整验收结果与交付制品信息将在完成后记录。自动化仅使用合成内容和回环 SSH 夹具，没有调用真实模型或重启生产任务。目标手机字体、覆盖安装、实际远端历史及另一台 tailnet 设备下载仍需真机确认。
