# 2026-11-03 嵌入代码卡片滚动修复

恢复基线 `ede45d2`（已发布 1.1.1 build 90），恢复登记 `5030904`。用户截图显示长 Markdown 围栏代码卡片，进一步确认主要现象为上下滑动时页面突然跳动。截图仅在本机会话检查，未加入仓库。

## 原因与修改

在外层消息页分发真实触摸、输入框原先持有焦点的合成场景中，轻触刚进入视口的长代码卡片，原生可选文字的焦点定位会把消息位置从 350 改为 552；后续视口尺寸变化还会再次尝试显示整个已聚焦的长文字区域。此前只有表格在横滑期间抑制这一定位，正文代码块与展开工具代码使用普通 HorizontalScrollView。另复现代码横向惯性尚未结束时，新的纵滑被内层截住。

提取已有表格方向交接为 `EmbeddedHorizontalScrollView`，正文代码、展开工具代码和表格共同使用。消息页在原生拦截前按屏幕坐标确定主方向，纵滑取消内层触摸并交给消息页，避免继续被旧横向惯性占有。卡片触摸时保留正常文字焦点，但抑制整块内容的纵向自动定位；松手后若视口尺寸变化，仍保持阅读位置。结束、取消与移除释放保护，显式矩形定位照常可用，长按选择与复制保持原生路径。没有改变外观、会话字段、存储格式、包名、签名、依赖、协议或远端服务。

需求 R-32、验收、架构与模块登记同步更新，文件规模预算未增加。

## 复现与定向验证

新增 `CodeBlockGestureTest`，在 API 26／35 各执行 12 项，共 24 项：长／窄围栏代码和展开工具代码聚焦及随后视口调整、横滑带轻微纵向偏移、双向纵滑的位移边界、旧横向惯性转纵滑、取消／移除、显式定位及原生选择复制。

负对照暂时将两个代码入口换回普通原生 HorizontalScrollView，其他测试输入与断言相同：24 项中 8 项失败、0 错误、0 跳过，涵盖两个 API 的三类卡片聚焦跳动和横向惯性阻挡纵滑。负对照完成后已恢复修复入口。修复后的 24 项全部通过；连同既有表格、正文复制、全屏代码手势和消息惯性回归，共 51 项通过，0 失败、0 错误、0 跳过。

本阶段为定向验证；完整验收与独立测试包版本阶段另行补记。合成测试复现了客户端焦点与惯性路径，不能证明用户手机上的全部跳动条件；真实触摸、厂商系统、输入法／顶部动画与覆盖安装仍需设备复测。
