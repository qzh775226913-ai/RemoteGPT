# 2026-10-26 相邻图片预下载与解码

需求 R-15；恢复基线 `470f5e5`，分支 `perf/image-neighbor-prefetch`。用户要求在查看图片时提前下载并加载附近几张，延续小范围修改与不处理远端图片文件缺失的边界。

ImageDialog 当前图显示后停留 150ms，在加载通道空闲时串行预下载与解码相邻前后各一张，按最近翻页方向优先。后台最多一个预取任务，沿用两个 worker 与最多三张／16 MiB 预览／40 MiB 原图缓存预算；预加载预算不足时保护当前图与方向优先邻图。没有新增会话字段、持久缓存、线程池或依赖，模块归属仍为既有 ImageDialog，因此不新增模块登记。

进入正在预加载的图片复用同一下载；翻到其他图取消过时任务，独立 generation 拒绝迟到结果。后台失败静默且不自动重试；主动打开失败图片仍显示既有重试入口。关闭移除 Handler 回调、取消任务并释放缓存和临时文件。布局、手势、保存、路径与 SSH 实现保持既有行为。

本轮增加合成图片与阻塞读取测试，检查当前完成后仅预取相邻、同步命中已解码图片、在途复用、迟到不覆盖、后台失败与主动重试，以及预算不足时当前图与方向邻图保护。定向 30 项通过（画廊 15／缩放 10／缩略图 5），0 失败／错误／跳过。关闭测试首次断言在异步 dismiss 监听器执行前检查取消状态，按 Android 消息队列推进后通过；并补查预加载原图容量准入与中途关闭文件清理。最终 1.0.63 完整验收通过：Android 429 项零失败／错误／跳过、Python 44 项通过，APK／结构／生成资产及 Lint 零阻断，20 项既有警告无新增；签名及本机 Tailscale 下载校验通过，见[交付记录](2026-10-26-1.0.63-tailnet.md)。

合成测试不能代表目标手机的网络与解码速度。快速连翻、预算不足或慢网络时邻图可能尚未就绪；远端原文件不存在仍无法预加载。没有调用真实模型、读取真实凭据或重启生产任务。
