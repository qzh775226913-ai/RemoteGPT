# RemoteGPT for Android

只保留远端对话的原生 Android 客户端。手机通过 SSH 的 exec/stdio 通道与远端 Codex App Server 通信，支持手机和平板，不需要额外开放 HTTP 或 WebSocket 端口。

## 安装

构建后的安装包：`app/build/outputs/apk/debug/app-debug.apk`。支持 Android 8.0 / API 26 及以上。

整理后的最新交付文件在 `dist/`：`RemoteGPT-1.0.16-debug.apk`、`RemoteGPT-1.0.16-source.zip` 及 `screenshots/`。本轮验证结果见 [TEST_REPORT.md](TEST_REPORT.md)。1.0.16 与旧版使用相同签名和应用 ID，可以直接覆盖安装，无需卸载旧版。

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

这是开发调试签名包，可安装试用。正式分发前需使用需求方自己的签名证书签署 release 包；本工程不包含任何生产签名密钥。

## 连接真实主机

1. 在远端安装支持 `codex app-server` 的 Codex CLI，并在远端完成登录。远端需要能访问其配置的模型服务。
2. 确认普通 SSH 能登录该主机，例如 `ssh user@host`。App 支持密码和 PEM / OpenSSH 私钥，支持私钥口令。
3. 在 App 中选择“连接电脑”，填写主机、端口和用户名，选择“密码登录”或“私钥登录”。底部“保存”只保存连接，“保存并连接”会同时启动连接。
4. 在“项目与启动设置”中填写项目的**绝对路径**，例如 `/home/me/project`。留空时使用远端程序的默认工作目录。
5. 启动命令默认 `codex app-server`。如果非交互式 SSH 找不到 `codex`，改为实际可执行文件的绝对路径。自定义命令必须提供相同的 JSON-RPC stdio 协议；交互式终端程序不能直接替代。
6. 首次连接时，与服务器管理员提供的 SHA-256 SSH 主机指纹核对，然后点“信任并连接”。公钥变化时连接会拒绝。
7. 连接成功后直接发送自然语言消息。左上角可查看并继续远端历史会话，右上角打开对话菜单，可新建对话或选择模型。

手机端没有模型 API Key 输入框，不读取开发环境中的 API Key。模型身份和权限由远端 Codex 的既有配置管理。

### 1.0.16 多会话同时工作

- 在同一 SSH 连接中，A 运行时可以切换已有的 B，或在当前/其他项目新建对话并发送。切换页面不再释放 A 的订阅；每条会话隔离消息、审批、草稿、模型与权限选择、运行/停止标记。只在首次创建会话、恢复历史或上传附件这些短暂操作期间暂缓切换。
- 全部通知复用已有样式和渠道。每个活跃会话独立创建流体云和会话气泡，使用独立的通知 ID、快捷方式与 PendingIntent；点击进入对应会话，审批也发送到对应会话。多会话流体云在短标题中标明会话名，正文仍展示最新进展。普通状态没有按钮，审批仅保留允许/拒绝，询问提供填写信息。
- 对话气泡直接绑定自己的会话，查看或审批不会把主界面切到另一条会话。后台会话完成后撤下其实时状态和气泡，当前会话保留原有空闲气泡行为。ColorOS 决定同时展示的卡片/气泡数量、聚合和轮换方式；应用为各会话分别提交通知。
- 仍复用一条 SSH 连接和既有独立托管进程，不为每条会话另起 tmux。手机进程退出不会主动停止远端；重连恢复托管的会话列表，并分别补回消息和待审批内容。任务遇到审批仍需等待用户处理。
- 托管端恢复一条会话时，补发其间其他会话产生的事件，防止并行输出遗漏。旧托管进程保持运行，新客户端在重放后额外读取其他已加载会话的快照进行兼容补齐；手机也保存已加载会话 ID，以兼容旧端没有会话列表的情况。
- 本机已部署新版脚本；已有正在工作的旧托管进程未被重启，继续使用兼容路径，新建托管实例使用新版。纯 stdio 模式退出手机后仍不保证远端存活，建议保留默认持久会话。

### 1.0.13 流体云与历史阅读冻结

- 面向一加 15T / ColorOS 16 新增独立的任务实时通知，沿用 Android Live Updates 标准接口申请流体云展示。短状态包括运行中、思考中、执行中、修改中、同步中、待审批。运行与待审批期间显示，空闲/完成/断线后撤下；已有会话气泡继续保留。
- 展开待审批卡片可查看命令、原因、路径、会话摘要并“允许一次／拒绝”；需要补充文字的请求通过“填写信息”打开完整对话。长命令摘要会截断，点击卡片可打开对话查看完整审批详情。
- 通知审批使用不可变 PendingIntent 和每个请求独立的随机 token，禁止过期卡片作用于同 ID 的新请求；重连、请求移除后旧按钮失效；同时从气泡/流体云重复点击只发送一次。锁屏要求解锁，消息重放时不提供审批按钮。
- “收起状态”只隐藏本轮实时通知，不会停止任务；本轮后续更新不会反复把它弹回来。对话菜单 → 后台连接设置 → 通知与流体云，可关闭本功能、检查系统是否允许实时通知并打开系统通知设置。气泡仍可单独保留。
- 系统和厂商拥有最终展示权。需要启用 RemoteGPT 的通知、实时通知/流体云，并保持“流体云 · 任务与审批”通知渠道开启。本版未连接一加真机，不能仅根据申请标记认定 ColorOS 已经展示流体云；若系统未提升，则呈现普通任务通知。更早 Android 保留普通任务通知。
- **阅读历史时冻结消息区**：后台仍接收事件，但不会改动当前消息文字、工具摘要、消息列表、处理中提示或插入加载完成的图片。上方内容增长也不会重新排版正在阅读的消息；回到底部/点向下按钮后补齐最新状态并保持跟随。
- 跟随状态下新增消息采用追加视图，已有消息不再因追加而全部移除重建。复制和工具详情使用当前显示内容的快照，避免阅读历史时内容被后台修改。
- 持久会话继续采用独立托管进程。tmux 可用于终端保活，但不能单独替代 JSON-RPC 事件记录、请求关联和审批恢复；当前加入 tmux 没有实质收益，未迁移或重启已有远端会话。需要开机自启和服务管理时再考虑 systemd。

实现依据：[Android Live Updates](https://developer.android.com/develop/ui/views/notifications/live-update)、[通知字段文档](https://developer.android.com/reference/android/app/Notification#EXTRA_REQUEST_PROMOTED_ONGOING)。构建 SDK 升至 36，最低支持版本仍为 Android 8，targetSdk 保持 35。

### 1.0.12 历史阅读、后台气泡与持久会话

- 查看上方消息时保留滚动位置；新增消息、流式文字、延迟图片和键盘/输入区变化不再强制滚到底部。原本位于底部时继续跟随；点“滚动到最新消息”或手动回到底部重新跟随。
- Android 11 及以上提供系统会话气泡，显示运行状态、审批摘要，展开后可查看命令/路径/原因并“允许一次”或“拒绝”。补充信息表单通过“打开对话”填写。系统需允许通知与气泡，可从“对话菜单 → 后台连接设置 → 通知与气泡”打开设置；较旧 Android 或关闭气泡时保留通知入口。锁屏通知采用私密内容可见性。
- 默认开启“项目与启动设置 → 远端持久会话”，远端要求 **Unix/Linux/macOS、Python 3.8+（含 sqlite3）和可用 SFTP**。第一次连接通过已验证主机指纹的 SSH/SFTP 安装托管脚本到 `~/.remote-gpt/`。不需要模型 API Key，也不改变远端现有 Codex 登录。
- 托管进程独立于 SSH 运行，仅监听权限为 0700 的用户目录中的 Unix socket，不开放 TCP 端口。杀掉/强制停止手机 App、关闭 SSH 或暂时断网后，远端继续运行；等待审批/补充信息时仍需用户回答，绝不自动同意。手机进程被强制停止期间，气泡和通知不能继续更新。
- 使用同一已保存连接重新连接后，恢复远端最后使用的对话，按顺序补回离线消息并接续实时输出，恢复尚未处理的审批。重连不会重新发送 `turn/start`，旧连接请求 ID 不会匹配新连接的请求；历史重放不会触发排队消息自动发送。一个连接配置只允许一个在线控制端，新连接替换旧连接。
- “断开连接”现在只断开手机，不等于停止远端任务；需要停止生成请先点对话中的停止按钮。关闭持久模式时仍使用原来的直接 stdio 连接，不能保证手机退出后远端继续。升级前由旧模式启动的任务不会自动迁移到托管模式，请完成旧任务后再重连。
- 托管身份由连接配置 ID 和启动命令确定：删除后重新创建连接或修改启动命令会创建另一托管进程。请复用原连接重连。远端操作系统重启、休眠、强制清理用户进程、磁盘满或 Codex/托管程序崩溃仍可能中断；本功能不是主机故障恢复或开机自启服务。
- 远端目录保存本次托管进程的消息事件（含对话/命令内容）、诊断日志以及 PID 文件，访问权限仅限远端用户；事件用于补回流式输出，随使用增长。停止使用前先结束任务，管理员可核对该目录的 `daemon.pid` / `server.pid` 后停止对应进程，再清理该连接的目录。不要在任务运行时删除目录。重启后的历史以 Codex 自己保存的会话为准。

气泡行为依据 [Android 官方说明](https://developer.android.com/develop/ui/compose/notifications/bubbles)，协议依据 [OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)。系统气泡由 Android/手机厂商设置控制，不是覆盖其他应用的自绘悬浮窗。

### 1.0.8 运行中发送方式

- 运行中输入文字并点发送，会弹出“发送方式”面板，可选“立即引导”或“稍后发送”。仅打开/取消面板不会发送消息；操作时校验当前对话与轮次仍然一致，防止对错误轮次发送。
- “立即引导”使用 turn/steer；“稍后发送”在当前轮正常完成后自动作为下一轮文字消息发送。每个对话最多保留一条待发消息，输入框上方显示单行预览，可取消。不会把另行选择的草稿图片附带发出。
- 停止/失败/断线时待发消息暂停自动发送，空闲时可点待发消息旁的发送按钮继续。队列按主机和对话隔离，保留于 App 进程内；系统杀进程后不保留，不声称后台持久队列。
- 包含更新后跟随最新位置、模型/推理强度面板、权限图标、字号设置与思考摘要请求修复。

### 1.0.7 跟随最新消息

- 消息更新后始终跟随最新位置，不再依赖“更新前是否接近底部”的判断。
- 对话内容按实际高度布局，并在消息区域或可视区域尺寸变化后重新定位底部，覆盖新增消息重建、流式文字变长、图片延迟加载和输入区域变高的情况。
- 暂停更新时仍可手动查看历史；下一次消息/状态更新会按用户要求返回最新内容。
- 包含 1.0.6 的推理强度面板、彩色权限图标、字体大小设置及摘要请求修复。

### 1.0.6 模型与推理强度、权限图标、字号

- 模型/权限面板具有淡入滑动进出动画，切换模型时强度选项淡入。权限图标与模型并排：灰色默认、绿色按需审批、蓝色只读、橙色完全访问。选项短标签，并保留图标形状和无障碍说明以辅助区分状态。
- 删除底部“SSH 加密连接 · 在你的电脑上运行”说明。
- 对话菜单 → 字体大小：跟随系统、小、标准、大、更大。以系统字号为基础缩放，设置保存在本机，立即重建界面并保留 Application 内的 SSH 连接与运行状态。
- `turn/start` 现在显式发送 `summary: auto` 请求可读思考摘要，所选强度通过 `effort` 字段发送。修复摘要含空项时不读取备用 content 的问题。未返回摘要时区分等待中/本轮无摘要；不生成或推测未公开的内容。
- 新摘要设置只影响后续轮次，无法补回远端未保存的历史思考内容。模型或服务仍可能不提供摘要，本轮已验证协议请求和解析，未对用户真实账户的输出作保证。

### 1.0.5 运行中引导、权限与后台恢复

- 运行中输入文字后，发送按钮通过 `turn/steer` 和 `expectedTurnId` 引导当前轮次，不会另开一轮；输入框为空时按钮用于停止生成。等待轮次 ID 或引导请求未返回时禁止重复发送。服务器拒绝引导时保留当前运行状态及可恢复草稿，错误详情可点“恢复消息”。当前引导支持文字，图片仍在空闲时添加。
- 思考详情支持摘要及服务器提供的 reasoning/textDelta、content，修复结束事件空摘要覆盖已流式收到的内容。展开详情持续刷新；未提供内容时明确说明。不会生成或推测服务器未公开的思考内容。
- 执行/思考详情折叠为单行，长命令省略，点按展开完整内容。
- 输入框下方新增审批权限：沿用远端、按需审批（项目可写）、只读、完全访问。选择从下一轮开始生效；运行中引导不会修改权限。不自动批准当前待审批请求；服务器策略仍可拒绝权限变更。
- 连接期间前台服务持有定时续期的 CPU 唤醒锁，断开时释放。切到后台保留 SSH/RPC 读取；返回前台时刷新列表，意外断线最多重试 3 次，并接续原对话。主动断开不会自动重连，检测到模型 WebSocket 403 时停止自动重试。
- 重新连接后自动打开该连接最后的对话；成功 resume 的线程继续监听实时事件。只读冲突页面在前台约每 3 秒读取保存的历史；它是轮询，不等同于其他客户端的逐 token 实时流。运行转动标识依赖服务器报告的 active 状态，未知状态不伪装为正在运行。
- “对话菜单 → 后台连接设置”说明电池策略并可打开系统设置。前台服务和唤醒锁不保证抵抗系统强杀、Doze 网络限制、VPN 退出或服务器进程崩溃；stdio 远端进程退出后无法凭客户端恢复仍在生成的任务。要保证完全断网期间继续运行，需要独立持久运行的远端服务；本版本未部署此类服务。

用户提供的 403 日志说明远端到 `chatgpt.com/backend-api/codex/responses` 的 WebSocket 请求被拒绝，EOF 说明 App 通道结束。不能仅凭该日志确定是登录、账户访问还是远端代理/网络策略；也不能证明是切后台导致 403。新版移除诊断中的 ANSI 控制符并给出有针对性的提示，未宣称修复服务端拒绝。

依据：[官方 OpenAI App Server](https://learn.chatgpt.com/docs/app-server)、[Android Wake locks](https://developer.android.com/develop/background-work/background-tasks/awake/wakelock)、[Android Doze 限制](https://developer.android.com/training/monitoring-device-state/doze-standby)。

### 1.0.4 用量、线程状态与当前对话

- 聊天页常驻项目路径、对话标题和剩余用量；点标题或项目路径查看完整项目路径、对话名称、ID 和状态，并可复制。项目路径独立保存在当前会话中，不受项目列表浏览影响。
- 连接后读取 `account/rateLimits/read`，监听 `account/rateLimits/updated`；按服务器返回的窗口显示剩余百分比，详情展示各额度桶和重置时间，可手动刷新。此处是账户额度，不是上下文剩余 token。服务器/登录方式不提供此接口时显示原因，不阻断聊天，不把未知额度显示为 0% 或 100%。
- 恢复线程优先使用实时 `status`；兼容旧服务器时只检查最后一轮，避免更早历史轮次遗留 `inProgress` 导致一直显示处理中。处理 `thread/status/changed` 和 `thread/closed`，清除过期可写缓存；缓存线程已卸载时重新接续。
- 新对话及成功切换对话时取消旧线程订阅。服务器何时卸载由其版本决定；取消订阅不保证即时释放远端写锁。
- 只读提示改为“尚未取得写入权限”，不再推断另一个客户端正在生成。点击“接续”重新请求原对话；“重连并接续”重建本 App 的 SSH / app-server 连接后恢复原对话，保留输入草稿和已上传图片引用。
- 关闭 Terminus 不一定结束远端 Codex / tmux 进程。若服务器持续返回 `already has an active writer`，本版不会强杀远端进程或删除锁；可复制诊断继续排查。本轮未连接用户目标主机，不能确认该次外部占用的具体原因已解决。

协议依据：[官方 OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)，并核对本机 CLI 生成的 JSON Schema。

### 1.0.3 图片、下载和菜单

- 输入框左下角“+”选择 PNG / JPEG / WebP / GIF 图片，每条消息最多 4 张、每张最多 20 MiB。可只发送图片，上传期间暂停发送；失败时保留已上传附件以便重试。系统文件选择器授权所选文件，不请求整个相册权限。
- 图片原始字节通过当前 SSH 的 SFTP 上传到远端用户目录 `~/.remote-ssh-attachments/`，目录权限 0700、文件权限 0600，文件名随机；用 `localImage` 作为 Codex 输入。上传后不会自动删除远端附件，以免历史引用失效；移除草稿图片只移除引用。需要时可自行清理该目录。

- Markdown 的远端绝对路径、项目相对路径、`sandbox:/...` 和 `file:///...` 链接可通过 SFTP 保存到系统文件选择器指定的位置，单文件最多 100 MiB；HTTP(S) 普通链接交给浏览器。`sandbox:` 路径必须在该 SSH 主机上实际存在，不能读取其他云端沙箱。HTTPS 图片重定向和需要网页登录的图片暂不支持。
- 左上角打开导航；聊天右上角为对话菜单；远程控制菜单提供连接/项目管理；进入项目后菜单改为“在此项目新建对话 / 刷新项目对话 / 复制项目路径”。
- 新增 Tailscale SSH 免密码认证模式，保留普通 SSH 密码/私钥方式。连接状态区分 TCP、SSH 认证和远端启动；取消会关闭正在连接的 socket。

### Tailscale 连接排查

手机须先运行并连接 Tailscale。本 App 不内置 Tailscale VPN。通过 Tailscale 访问普通 OpenSSH 时仍选择密码或私钥；只有服务器启用 Tailscale SSH 身份认证时才选择免密码方式。

若出现 `ConnectException / ECONNABORTED / failed to connect ... after 20000ms`，连接尚未进入 SSH 身份认证；切换密码/私钥不会解决 TCP 不通的问题。先确认同一台手机的另一个 SSH 客户端能连接完全相同的地址和端口，再检查 Tailscale 的“头像 → App-based split tunneling”，确保 Remote（`app.remotessh`）没有被排除，检查系统联网限制与 Tailscale 的在线状态、访问规则。日志中的源 IP 不足以单独证明 VPN 是否被绕过。

依据：[Tailscale 按应用分流](https://tailscale.com/docs/features/client/android-app-split-tunneling)、[Tailscale SSH 认证](https://tailscale.com/docs/features/tailscale-ssh)、[Codex App Server](https://learn.chatgpt.com/docs/app-server)。实际用户设备上的 VPN 路由尚未验证，免密码模式的测试使用本地模拟服务器，不等于真实 tailnet 验收。

- 错误横幅约 6.5 秒后自动消失（无障碍设置可能延长）；点击横幅查看并复制完整诊断，消失后仍可从远程控制菜单“最近一次错误”查看。本次截图错误被截断，尚不能独立确认完整服务器错误；新版会提供完整代码和原因。

## 实现范围

这是独立的 SSH 客户端实现，不是官方 ChatGPT App，也没有使用其私有接口。本轮已参考用户提供的手机截图调整项目导航；仍缺少完整交互录屏、字体和动画规格，因此**没有验证“所有界面和动画细节完全一致”**。

目前没有实现非图片附件上传、语音、文件内容编辑器、全量历史服务器搜索或应用内远端登录。1.0.12 的持久任务托管范围见上文。目录浏览和已加载列表搜索已实现。未知的远端交互请求会明确返回不支持，不会自动批准。模型服务要求登录时，需要在远端完成登录后重连。非 Codex 程序需要自行提供兼容协议适配器。

连接中应用退到后台时由前台服务维持 SSH。1.0.12 开启持久模式时，SSH 断开不关闭远端 Codex 输入，重连后补回消息；关闭持久模式仍有原先的生命周期限制。远端主机或托管进程故障不在持续运行保证范围内。

## 结构
